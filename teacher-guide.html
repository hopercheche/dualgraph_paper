Faculty review guide and forms

Existing station rules; independent evidence review; reasons recorded at the point of disagreement.

Review using the existing CUHK standards

The original station checklists and faculty clarifications define the standards. They do not need to be invented again. Faculty review is still needed to determine what a particular recording actually demonstrates: who spoke, whether a prompt was delivered, which medicine was discussed, and whether an error was corrected.

Prepare the reference before examining A/B predictions. A second reviewer, if available, first reviews a prespecified subset independently; retain initial disagreements before reconciliation. A single reviewer produces a single-expert reference, not an independently established two-rater gold standard.

A simple, directly fillable role review form

Complete one form per sampled reply. “Not applicable” must follow the prespecified checklist, not be assigned after seeing a failure. An allowed but optional behaviour is not a required answer.

CheckJudgmentQuote/time and reason for any problem
1. Required response: obligatory information is supplied when its approved trigger is met.
2. Case fidelity: identity, history, medicines and current role knowledge remain consistent.
3. The role does not reveal prohibited knowledge or present newly supplied information as prior patient knowledge.
4. Provenance and time: the reply uses preceding events with correct attribution, medicine bindings and correction state.
5. Prompt control: the prompt is authorised, timely, correctly targeted and not repeated after consumption.

Reply compliance = 1 only when there is a valid reply and every applicable required/prohibited check passes. Otherwise it is 0. These five categories explain failures; they are not averaged into the primary score. For offline replay, judge the finalized reply of the first prespecified run after the fixed audit/retry policy. It need not be played to a student; actual delivery is a separate live-event property.

A simple assessment reference form

Use the same identified criterion for both systems. A correct student answer can coexist with a prompt-dependent grade cap. A patient’s repetition is not new student evidence. Do not infer a whole-station grade from one short checkpoint.

Assessment exact match = 1 only if the system state and all prespecified applicable fields match the faculty reference. Compare the complete normalized applicable-effect and review-reason sets; agreement on a yes/no review flag alone is insufficient. A failed output is 0 and remains in the denominator. Applicability and codes must be frozen before A/B outputs are examined.

What to report

Report the actual number of reviewed prefixes and replies, independent-review coverage, raw agreement and disagreement types. Cohen’s κ may be reported when the category distribution makes it meaningful; it can be undefined when all ratings fall in one category. Do not force ICC onto unordered decision categories. [R21·1]

The planned technical set contains 120 checkpoints, 30 per station. Multiple checkpoints from one recording remain correlated. Faculty workload should be measured in a small trial, then budgeted by actual review units—not by assuming that 16 recordings means 16 independent students. Verify recording eligibility and completeness before final labelling.
