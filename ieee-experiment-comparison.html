RESEARCH AND STUDY MATERIALS

Study methods in IEEE education research

Full-text comparisons of sample units, controls, expert references and component ablations.

Three useful design principles

Same task, different method

Fix the model, knowledge, station rules and frozen history. Compare conventional RAG with DualGraph-OSCE on exactly the same checkpoint.

Independent assessment reference

Faculty label the evidence before seeing system predictions. Student satisfaction and plausible model rationales are not the reference.

One mechanism per ablation

Reuse a cached Evidence Graph and remove only the propagation from a delivered role intervention to its assessment consequence.

EDUCON and FIE are conferences; Transactions on Education and Transactions on Learning Technologies are journals. These papers offer useful study designs but no universal minimum number of students, cases or trials.

What the ablation removes

The full method uses a delivered prompt event when applying the approved consequence of that prompt. The ablated method uses the same Evidence Graph, correct student answer, medicine bindings and rubric, but blocks only the edge that transfers the role intervention to the assessment consequence.

For the onychomycosis example, both versions should recognise that the interaction was eventually explained. The question is whether the prompt-dependent C+ cap is preserved. C+ is a ceiling, not an automatic final grade.

Keep negative controls: an unsent prompt draft, an ordinary clarification and an independent answer should not acquire a cap. The diuretics station does not inherit the onychomycosis cap. This ablation tests assessment consequences; unchanged role generation means it cannot by itself prove an improvement in role generation.

Study design derived from these methods

QuestionPlanned testInference boundary
Does the overall method help?120 frozen checkpoints, 30 per station; identical inputs for A conventional + RAG and B DualGraph-OSCE.Two endpoints: first-reply role compliance and assessment exact match. Checkpoints from a source recording remain a cluster.
Does the shared intervention relation matter?Replay the same cached B evidence with FULL and UNLINKED; no new extraction or dialogue generation.Interpret the affected subset and negative controls separately. Do not select cases after seeing effects.
Does the platform support natural use?Review the eligible October 7 live recordings and report completion, technical failures and experience responses.A short, incomplete attempt is not a complete consultation. Natural use does not alone establish learning gain.
Are reference decisions reliable?One expert labels all planned units; a second independently checks a prespecified subset if available.State the actual review coverage. Agent annotations in local audit files are not faculty gold labels.

What the paper must disclose

  1. Define the reference, endpoint and denominator before running A/B.
  2. Retain failures, missingness, negative findings and actual completion counts.
  3. Distinguish checkpoints, source recordings, students, repeats and rubric fields.
  4. Publish shareable station-neutral schemas, rule versions and frozen benchmark identifiers within the consent limits.
  5. Use source-cluster uncertainty estimates when several checkpoints share a recording. An independent-pair McNemar calculation is a planning illustration, not a valid substitute for that dependence.

Neither IEEE precedent nor a target of 120 guarantees statistical significance or publication. The effect size, reference quality and source diversity determine what the study can support.
